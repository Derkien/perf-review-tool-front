# perf-review-tool-front

SPA для Performance Review Tool (GRI): Vue 3 + Vite + TypeScript + PrimeVue (Aura) + ECharts.
Отдельный репозиторий от API; поднимается в compose из `perf-review-tool-api`.

## Запуск

В Docker (рекомендуется): `cd ../perf-review-tool-api && docker compose up -d` → http://localhost:8080

Локальная разработка:

```bash
npm install
npm run dev      # vite на :5173, /api проксируется на localhost:8000
npm run build    # типы + прод-сборка
npm run test
```

## Экраны

- Дашборд цикла: стадия/дедлайны, счётчики, распределение A–E, «кого пушить» по отделам
- Сотрудники: таблица с фильтрами → карточка (профиль, вилка с положением, спарклайны эффективности/светофора, радар компетенций с нормой грейда, история ревью)
- Моё ревью: селф-ревью с динамическими лимитами из админки + выбор пиров (команда обязательна)
- Оценить коллег: пайр-оценки словесной шкалой A–E + свободная ОС
- Валидация пиров (рукли): добавить/убрать, отправка заданий
- Калибровки: создание сессий, AI-пакет export/import, сессия с очередью по грейдам, карточка инсайтов (рекомендация системы с вкладами компонентов, AI-предсказания, пиры, рукли, эффективность, радар), голосование → вскрытие → финал ведущего, передача ведущего
- Решения: inline-таблица, warnings правил, бюджет ФОТ с прогресс-баром, экспорт
- Номинации: подача руклями, статусы СТО, экспорт (к подаче до 4.09)
- Импорт: preview → конфликты → apply по 6 типам файлов
- Админ: пользователи/роли, лимиты, веса автокалибровки, правила рейзов
